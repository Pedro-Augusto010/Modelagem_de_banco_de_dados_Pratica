# 🚌 Projeto de Modelagem de Banco de Dados — FlixBus (Demanda Fictícia)

Este projeto foi desenvolvido com o objetivo de praticar e consolidar os conceitos de **modelagem lógica de banco de dados**, cobrindo todas as etapas iniciais de levantamento e estruturação até a geração das tabelas e relacionamentos.

---

## 🎯 Objetivo
Simular um cenário real de negócio baseado no funcionamento da **FlixBus** para exercitar o processo de engenharia de requisitos, mapeamento de regras de negócio e abstração dos dados para um modelo relacional bem estruturado.

---

## 📋 Etapas do Projeto

1. **Levantamento de Requisitos e Dados:**
   - Mapeamento das entidades principais da operação (ex.: passageiros, viagens, rotas, ônibus, passagens e pagamentos).
   - Definição das informações necessárias para a gestão do serviço de transporte.

2. **Definição das Regras de Negócio:**
   - Estabelecimento de restrições e cardinalidades (ex.: uma passagem pertence a apenas um passageiro; um ônibus pode realizar múltiplos trajetos).
   - Garantia da integridade referencial entre os dados.

3. **Modelagem Lógica (dbdiagram.io):**
   - Criação do diagrama entidade-relacionamento (DER) lógico.
   - Definição de chaves primárias (PK), chaves estrangeiras (FK), tipos de dados e atributos de cada entidade.

---

## 🛠️ Ferramenta Utilizada

- **[dbdiagram.io](https://dbdiagram.io/)** — Criação do modelo lógico e exportação do esquema relacional/DDL.
